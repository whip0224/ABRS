# 途號

個人用的香港巴士工具。用現時位置或地名找出可到達、途經的路線，並顯示到站時間。路線、收藏和常用地點都存在這部手機裡。

## 在電腦跑

```bash
npm install
npm run dev
```

瀏覽器打開 http://localhost:8080 。

## 放到 GitHub

1. 解壓這個壓縮檔。
2. 在 GitHub 新增一個空的 repository。
3. 在解壓出來的資料夾裡：

```bash
git init
git add .
git commit -m "途號"
git branch -M main
git remote add origin https://github.com/你的帳號/你的repo.git
git push -u origin main
```

不要上傳 `node_modules`。

## iPhone

用 Safari 打開網站，點分享，再點「加入主畫面」。主畫面圖示是紅色雙層巴士。如果之前加過舊圖示，先刪掉再加一次。
